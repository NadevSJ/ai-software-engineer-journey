# AI Software Engineer Journey

This repository holds my practice code, exercises, study notes, and small builds from the STEM Link AI Software Engineer track. I use it to keep a clear record of what I am learning and building as I work through the program.

## Weekly Rhythm

- **Sunday :** Live class session
- **Monday to Saturday :** Daily hands-on practice, coding exercises, and regular commits

## Core Rule

- **Zero AI-generated code :** No AI tools are used to write, generate, or complete any code in this repository.
- **100% hands-on ownership :** Every line of code is written, run, tested, and debugged by me so I build real problem-solving skill and dependable habits from the ground up.

## Folder Layout

- `python/` - Python scripts, exercises, and core programming practice
- `css/` - Styling experiments and layout fundamentals
- `javascript/` - JavaScript exercises and logic practice
- `class-notes/` - Notes and takeaways from class sessions
- `projects/` - Practice projects and applied exercises
- `practice/` - General drills and scratch work
- `log.md` - Daily log tracking ongoing work and consistency
- `.gitignore` - Keeps `.env`, virtual environments, caches, editor folders, and `node_modules` out of Git
